# Church experts as connected settlement opinions

This opt-in experiment brings the older church cleanup experts into the coupled
inference/settlement test. It leaves ordinary conversion, the earlier six-pass
study and the exact 64-pass replay unchanged.

The green curves in those reviews are the **working interpretation of acquired
ink**. They are not rendering artifacts. The colored construction boundaries are
a separate interpretation. A construction can explain an ink interval without
deleting it, and the surviving ink graph can still be wrong. The new review opens
with construction shapes and faint acquisition; green working ink is optional.

## What runs

1. Import the exact retained, game-recognized acquisition and fitted annotation.
   Reuse the same frozen repair, line and closure providers. No new model trains.
2. Reconsider unused intervals with the existing enclosure/opening expert.
   Admission requires containment, sufficient outline support, an appropriate
   scale, and no substantial duplication of an existing opening. There is no
   assumption of exactly two windows. Failed claims remain unresolved.
3. Run the existing cleanup experts to propose construction families, parents,
   foreground choices, support, repeated pairs and optional additions. Their
   complete output remains a qualified proposal, not a true church annotation.
4. Compile those choices into executable native shape constructions and generic
   affine obligations over exposed left/top/right/bottom ports. Observed parts
   start at their **source-estimate bounds**, not the cleanup's final coordinates.
   Intrinsic construction replacements—such as centering a triangular peak or
   changing the selected opening head—have native before/after witnesses.
5. Each outer pass rereads the changed ink graph with the local providers. The
   chosen shape/support/pairing hypotheses remain fixed for this bounded run.
   Native error relations then negotiate the selected number of inner rounds.
   Shape, ink, containment, support and repetition opinions can resist each other.
6. Publish only accepted ink displacement. Import the next world's shape bounds
   through retained public-port correspondences. Record transfer accounting and
   unresolved strain. Native archives are independently restored before acceptance.
7. Read wall partitions from current public building/tower bounds. These cells
   are derived constructions, with native projection/selection witnesses and
   boundary edges, rather than independent rectangles that can drift apart.
8. Recompute source/boundary coverage for the review. Orange identifies source
   intervals without a selected explanation; dashed gray identifies expected
   boundary portions without a selected ink correspondence. Neither read changes
   the acquisition or makes an invented line into observed evidence.

The old cleanup is therefore an expert **proposal generator**, not a final
coordinate target. Its absolute final positions do not enter the parameter
objective. Relative support, size and placement opinions do enter, explicitly as
authored hypotheses. Repeating them over passes is not independent evidence.

## Which older rules are used

| Existing expert | Treatment here |
|---|---|
| Body, doors, windows, towers, roofs and crosses | Reuse source-supported initial part proposals and their source intervals. |
| Front-like versus side/oblique presentation | Reuse the provisional view selection; do not impose the same reflection assumptions on both. |
| Symmetric triangular roof, dome, side parallelogram | Propose the corresponding native construction family; retain its shape correspondence. |
| Roof on wall/tower; width and centering | Native relative-extent and attachment errors over both participants' ports. |
| Upper tower footprint supported by wall | Native horizontal support/overhang inequalities and base attachment; grounded side towers are a different hypothesis. |
| Continuous foreground wall versus projecting tower | Reuse the existing source-conditioned foreground choice; partition from live bounds. |
| Paired caps suggesting a missing supporting tower | Explicit prior-only part, followed by the same support and pairing opinions. |
| Mirrored towers, caps and crosses | Selected pair reflection, shared extent, head and base expectations. |
| Cross on moving peak/top; face-relative cross | Native support attachment or relative support-level expectation. |
| Large crosses, outlined crosses, bar above halfway | Reuse the existing size/family/bar proposals; observed extent still supplies a competing seed allowance. |
| Rectangular, arched, round and paned openings | Reuse the chosen opening construction; repetition can propose a common head. Source-supported and prior-only remain distinct. |
| Window matching around a door/local facade | Selected mirror pair and equal size/level, rather than an unconditional two-window count. |
| Opening containment and edge margins | Native inequalities referencing the chosen parent frame. |
| Opening/door clearance | Select a separation lane from the proposal; native gap error over both openings and the owner extent. |
| Door base and circular-window aspect | Native base attachment and equal-diameter opinion. |
| Optional absent door | Reuse the conservative existing entrance proposal; gray/dotted, without a physical ink mapping. |
| Near horizontal/vertical lines | Existing learned line gating and native axis-continuity errors. |
| Interior angular site in a curved source span | Limited, source-supported knot proposal near a selected construction corner; preserve both source intervals and then settle its port. |
| Local joins, endpoints, gaps, overshoots, continuation and closure | Existing local providers and native graph replacements rerun on each changed graph. |
| Unexplained ink | Retry existing enclosure expert, plus visible per-pass residual intervals. Unknown remains available. |
| Missing ink | Explicit expected-boundary remainder, not an acquired stroke. Existing closure provider is separate. |

There is no general physical simulation, camera recovery, text recognition or
universal object discovery. The error structures express these selected premises;
they do not prove that a floating tower is impossible in every depiction. The
shared-cell wall decomposition does not declare contacts just because two
independently read coordinates happen to agree.

## Settlement mathematics and limitations

For each native affine error, read `s = sum(a_i * p_i)` in its declared basis.
An allowed interval `[low, high]` gives the requested correction
`clamp(s, low, high) - s`. The signed excess, inverse coefficient participation,
authored response shares, passage admission and actuator receipts remain in the
Gojo graph. The existing direct/clipped/trend-damped response ensemble, damping,
finite movement budgets and quarter-unit quantum are retained.

The compiled fractional coefficients use 256 feature ticks per coarse unit.
Their response-clipping intervals use that same calibration. Leaving a clip at
the old tick count would silently weaken an equivalent relation after changing
its resolution. A focused regression test compares coarse and fine versions
over multiple rounds, including accepted displacement and quantum remainder.
The receiver's own passage, capacity and movement limits are not enlarged.

An overhang error cannot erase itself by changing an independent error variable:
its value is a read of the actual participating bounds. It can ask both wall and
tower to respond. Accepted, blocked, capacity-deferred, candidate-rejected and
quantum participation remain accounted for separately.

The current adapter still proposes topology before negotiating its parameters.
It does not continuously rediscover a roof, change a window's parent or split an
object in response to later strain. In particular, the residual-ink retry occurs
once at admission, while the coverage diagnostic is reread at every saved pass.
A future inference epoch can use persistent unexplained ink or blocked strain
to request new hypotheses. A low geometric strain is not semantic accuracy.
Source/seed influence does not decay on a schedule in this experiment.

## Run and inspect

```powershell
python -m gojo_quickdraw.church_refine --source-study D:/_quickDraw/data/church-duration-2026-10-29-v2 --output D:/_quickDraw/data/my-church-experts --passes 8 --steps 2 --limit 10
```

An optional `--selection FILE.json` lists explicit identities. A row can name
another completed study using the same frozen providers:

```json
[{"id":"0301c0037e88809800a99f23b9a67eb50896786c",
  "study":"D:/_quickDraw/data/church-settlement-2026-10-29-v2"}]
```

Use a separate output and work folder. Bounds are 32 drawings, 16 outer passes,
eight inner rounds. Default work stays under `D:/_quickDraw/_work`. The review
is `OUTPUT/review.html`: six common-frame panels, optional ink layers, per-pass
selection, relationship mismatch and keyboard navigation. The native archive
retains every executed pass; the review's selected milestones are projections.

`inputs` retains exact source plus compiled hypothesis requests; `proposals`
retains the qualified expert output; `baseline` retains earlier views; `models`
retains exact provider bytes. The native producer writes `drawings/ID/view.json`
and `bidirectional.gojo.bin.gz`. `analysis.json` contains descriptive coverage,
part counts and remaining strain. It is not a training accuracy report.

The independent native auditor also checks derived wall constructions:

```powershell
dotnet run --project tools/church-audit/ChurchAudit.csproj -c Release -- OUTPUT 16 OUTPUT/native-audit.json
```

Older proof histories may be retired under an explicit retention receipt. Keep
source snapshots, provider bytes, views and cohort identities so the exact
acquisitions remain reusable. Do not silently present a deleted native archive
as available, and never remove user-created datasets or raw QuickDraw data as
part of experiment cleanup.
