# Authored controls

`churches.ndjson` contains synthetic acquisition controls, not QuickDraw data:

- A frontal outline with a door, two windows, and a cross.
- An outline with no acquired lower boundary, for inspecting a separate hidden
  ground hypothesis.
- An empty acquisition, which must remain open rather than becoming a church.

The example perturbation fixture is available through `probe --example`.
It compares a mirror, an anchored translation, and a centered translation using
the same intervention. The first and third can tie; this does not identify the
unknown human construction process.
